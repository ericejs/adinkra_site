# Adinkra Produções Artísticas — site institucional

Site responsivo desenvolvido em HTML, CSS e JavaScript puro, com base no PDF de apresentação fornecido.

## Como visualizar
1. Extraia o arquivo ZIP.
2. Abra `index.html` no navegador.
3. Para melhor experiência, use uma extensão/servidor local (por exemplo, Live Server no VS Code).

## Estrutura
- `index.html` — conteúdo e estrutura das seções.
- `css/style.css` — identidade visual, layout e responsividade.
- `js/script.js` — menu mobile, filtros do portfólio e ano automático.
- `assets/` — imagens extraídas do PDF original.

## Conteúdo preservado
O site contempla apresentação de Ariene Dupin, explicação do nome Adinkra, três frentes de serviço, tabela completa de serviços e valores, quatro trabalhos realizados, contato e assinatura no rodapé.

## Observações para publicação
- Os botões dos trabalhos abrem as imagens dos materiais que estavam disponíveis dentro do PDF. Se a artista tiver links públicos para os projetos completos (PDFs, vídeos ou páginas), substitua os `href` desses quatro links em `index.html`.
- Os contatos foram configurados com o telefone e e-mail presentes no documento.
- As fontes Manrope e DM Mono são carregadas do Google Fonts; sem internet, o navegador utiliza fontes alternativas.
- O texto “doutoranda em Artes visuais pela USP” e os valores foram mantidos conforme o material de apresentação fornecido. Confirme se permanecem atualizados antes de publicar.
